# Astro

Agents and skills for [Astro](https://astro.build) projects. Names in this section start with `astro-`.

## Agents

| Agent | What it does |
| :- | :- |
| [astro-developer](agents/astro-developer.md) | Builds pages, layouts, components, routes and content collections following the project's own conventions, and verifies with `astro check` and a production build |

## Skills

| Skill | What it does |
| :- | :- |
| [astro-verify-build](skills/astro-verify-build/SKILL.md) | Pre-commit gate for Astro: `astro check`, lint and format, the production build, and the site as served |
