## Working economy

- The main session plans, decides and reviews; agents build. Make one-line fixes yourself, and group related bugs into one agent run.
- Brief an agent once and fully: the goal, the exact files or sections to read, what is already decided, the budget, whether it may commit, and the report format with a word limit.
- Read only what the task needs: named files and sections, never whole folders. Search first, then read line ranges of large files.
- Look at an image only to judge something you just made, and only once.
- Reports stay under 150 words: what changed, what ran, what failed, what is open.
- Resume an agent that already has the context instead of starting a new one. Commit only after every writing agent has finished.
- Use the cheapest model that does the job well: a mid-size model to build, a small one for mechanical work.
- Paid generation: estimate the cost first, then mock-up, pilot and production, each approved by the owner. Ask before any batch over the agreed limit. After stopping an agent, check the jobs it already sent.
